# 仕様: 画面と操作

対象: `MainWindow`, `ChannelDetailPanel`, `ChannelFilterService`, `SettingsDialog`, `FavoritesDialog`

## 1. メインウィンドウの構成

```
┌──────────────────────────────────────────────┐
│ [更新] [お気に入り] │ [設定] │ (取得中のみ進捗バー)  │ ツールバー
├──────────────────────────────────────────────┤
│ [検索テキスト                    ] [フィルタ ▼] │
├──────────────────────────────────────────────┤
│ ┌ チャンネル一覧 ┬ 録画中 (N) ┐                 │
│ │ 一覧                                        │ タブ
│ │ ───── GridSplitter ─────                    │
│ │ 詳細パネル                                   │
├──────────────────────────────────────────────┤
│ 123チャンネル / 456人視聴中        次回更新: 42秒後 │ ステータスバー
└──────────────────────────────────────────────┘
```

タイトルは `YPBrowser`。既定サイズ 900×600（起動時に `Window` 設定で上書き）。

| 部品 | 動作 |
|---|---|
| 更新ボタン | 手動更新（最小フェッチ間隔を無視） |
| お気に入りボタン | お気に入りダイアログをモーダル表示 |
| 設定ボタン | 設定ダイアログをモーダル表示 |
| 進捗バー | `IsRefreshing == true` のときだけ表示（不確定アニメーション） |
| 検索ボックス | 1 文字入力するたびに再フィルタ |
| フィルタ | すべて / 新着 / お気に入り / NG / ログ の 5 択 |
| ステータスバー左 | `{N}チャンネル / {M}人視聴中`（初期値 `準備完了`、録音操作時は `録音開始: …` などを一時表示） |
| ステータスバー右 | `次回更新: {N}秒後`、次回時刻を過ぎている間は `更新中...`（1 秒ごとに更新） |

## 2. チャンネル一覧タブ

### 2.1 行の表示

3 列・各セル 2 段。

| 列 | 幅 | 1 段目 | 2 段目 |
|---|---|---|---|
| チャンネル名 | 可変（最小 120） | `ChannelName` | `GenreDescription`（空なら非表示） |
| 視聴/リレー | 75（右寄せ） | `{Listeners}/ {Relays}` | `BroadcastTimeStr` |
| ビットレート | 65（右寄せ） | `BitrateKbps`（`0` 以下は空） | `ChannelType` |

長い文字列は末尾省略（`…`）し、チャンネル名と詳細はツールチップで全文を表示する。

`GenreDescription` の書式:

```
[ジャンル - 説明] 「コメント」
```

- ジャンル・説明は空でないものだけを ` - ` で連結。両方空なら `[]` ごと省略
- コメントが空なら `「」` ごと省略

### 2.2 色

| 対象 | 条件 | 色 |
|---|---|---|
| 行の背景 | お気に入り一致 | `FavoriteSettings.BackColor` |
| 行の背景 | `Diff == Log` | `#EFEFEF`（お気に入り色より優先） |
| チャンネル名の文字色 | `Diff == New` | 緑 `#008000` |
| チャンネル名の文字色 | `Diff == Up` | 青 `#0000C8` |
| チャンネル名の文字色 | `Diff == Down` | 赤 `#C80000` |
| チャンネル名の文字色 | `Diff == Log` | 灰 `#808080` |
| チャンネル名の文字色 | `None` / `Changed` | 既定色 |

これらの色はコード・XAML 内の固定値で、`DisplaySettings` からは変更できない。

### 2.3 詳細パネル

選択行が変わると内容を差し替える（選択なしのときは全項目空）。

| 表示項目 | 値 |
|---|---|
| チャンネル名 | `ChannelName` |
| ジャンル / 説明 / コメント | `Genre` / `Description` / `Comment` |
| 視聴者 | `{Listeners}人 / リレー{Relays}` |
| ビットレート | `{BitrateKbps} {ChannelType}` |
| トラック | `TrackInfo`（`Artist / Title / Album` を空要素を除いて ` / ` 連結） |
| YP | `YpName` |
| コンタクト URL | `ContactUrl`。絶対 URI ならリンクとして扱い、クリックで既定ブラウザを開く |

高さは `GridSplitter` で 80〜300 の範囲に調整でき、終了時に保存される。

## 3. フィルタ

`ChannelFilterService.Filter(channels, filterIndex, searchText)`。

| index | 表示名 | 条件 |
|---|---|---|
| 0 | すべて | `Diff != Log && !IsNG` |
| 1 | 新着 | `Diff == New`（NG も含む） |
| 2 | お気に入り | `IsFavorite && !IsNG` |
| 3 | NG | `IsNG` |
| 4 | ログ | `Diff == Log`（NG も含む） |

検索テキストは前後空白を除去し、空でなければ以下のいずれかに部分一致（大文字小文字無視）するものだけを残す。

```
ChannelName / Genre / Description / Comment
```

表示順は「お気に入り（`IsFavorite`）を先頭」→「`Listeners` 降順」。

## 4. コンテキストメニュー（チャンネル一覧の右クリック）

すべて**選択中の行**に対して動作する。

| 項目 | 動作 |
|---|---|
| 再生 | 既定プレイヤーで開く（下記 4.1） |
| コンタクトURLを開く | `ContactUrl` を既定ハンドラで開く（空なら何もしない） |
| 統計URLを開く | `StatsUrl` を既定ハンドラで開く（空なら何もしない） |
| お気に入りに追加 | 下記 4.2 |
| お気に入りから削除 | `IsRegex == false` かつ `Word == ChannelName` のお気に入りをすべて削除 → 保存 → 再マッチ |
| コピー（チャンネル情報） | 下記 4.3 の書式でクリップボードへ |
| コピー（プレイリストURL） | `StreamUrl` をクリップボードへ |
| 録音/録画 | 録音の開始・停止をトグル |

いずれも失敗時に UI 上のエラー表示はない（URL を開く操作は例外を握りつぶす）。

### 4.1 再生時のプレイヤー選択

```
IsDefault == true のプレイヤー
  └─ 無ければ Players の先頭
        └─ 1 つも無ければ OS の既定ハンドラで StreamUrl を開く
```

プレイヤー起動時は `ArgumentTemplate` の `{url}` を `StreamUrl` に置換し、`UseShellExecute = false` で起動する。
プレイリストファイルは生成しない。

### 4.2 「お気に入りに追加」で作られるルール

| フィールド | 値 |
|---|---|
| `Title` / `Word` | `ChannelName` |
| `TargetFields` | `["ChannelName"]` |
| `BackColor` | `#FFFF99` |
| `TextColor` | `#000000` |
| その他 | `FavoriteSettings` の既定値 |

追加後すぐに保存し、全チャンネルを再マッチして表示を更新する。

### 4.3 「コピー（チャンネル情報）」の書式

```
{チャンネル名} ({視聴者数}/ {リレー数})
 [{ジャンル} - {説明}]「{コメント}」
 {アーティスト / アルバム / 曲名}
{コンタクトURL}
```

コメントが空なら `「」` ごと、トラック情報が全て空ならその行ごと出力しない。

## 5. 録画中タブ

タブ見出しは `録画中 (N)`。N は**終了済みを含む**エントリ数。

| 列 | 幅 | 内容 |
|---|---|---|
| 停止 | 44 | `IsActive` のときだけ表示されるボタン |
| チャンネル名 | 140 | `DisplayName`（終了後は `…（終了）`）。ツールチップは保存先フルパス |
| チャンネル詳細 | 可変 | 録音開始時点の `GenreDescription` |
| ダウンロードステータス | 130（右寄せ） | `(H:MM:SS) 1,234KB` |
| リトライ | 40（右寄せ） | 再試行回数。`0` のときは空欄 |

| 挙動 | 仕様 |
|---|---|
| 追加位置 | 新しい録音を先頭に挿入 |
| 行の背景 | 録音中は `#EDE7F6`、終了後は白 |
| 終了時 | エントリは削除されず `IsActive = false` になって残る |
| 経過時間 | 録音中のみ 1 秒ごとに進む。終了後は停止時点で固定 |
| 永続化 | しない（アプリ終了で消える） |

## 6. キーボード・マウス操作

| 操作 | 動作 | 有効な場所 |
|---|---|---|
| ダブルクリック | 選択チャンネルを再生 | チャンネル一覧 |
| Enter | 選択チャンネルを再生 | チャンネル一覧 |
| F5 | 手動更新 | チャンネル一覧（フォーカスがあるとき） |

## 7. 起動と終了

```
起動: MainWindow 表示
        └─ Loaded
             ├─ 設定読み込み
             ├─ 通知サービス初期化
             ├─ 1 秒周期タイマー開始（次回更新カウントダウン + 録音の経過時間）
             ├─ 自動更新開始（即座に 1 回取得）
             └─ Window.Width/Height、SplitterPosition を復元

終了: Closing
        └─ Width / Height / SplitterPosition を保存
```

起動時のフィルタは常に「すべて」（`ActiveFilterIndex` は復元されない）。
最小化状態での起動・トレイへの最小化は未実装。

## 8. ダイアログ

### 設定ダイアログ（モーダル）

左のナビゲーションで 7 ページを切り替える。

```
Yellow Pages / プレイヤー / 表示 / ネットワーク / 通知 / 動作 / ダウンロード
```

下部に OK・キャンセル。OK で保存して閉じる。キャンセルは閉じるだけ（[settings.md](settings.md#4-設定ダイアログのキャンセル挙動)）。

### お気に入りダイアログ（モーダル・独立ウィンドウ）

お気に入りルールの追加・削除・並べ替えと、対象フィールド 9 種のチェックボックス、
検索語・正規表現・NG・色などを編集する。チェックを全て外した場合は `["ChannelName"]` に戻る。
OK で保存して閉じる。

編集結果が一覧の色分けに反映されるのは、次回の更新（`MatchAll` 実行時）以降。
