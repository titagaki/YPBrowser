# 仕様: 画面と操作

対象: `MainWindow`, `ChannelDetailPanel`, `ChannelFilterService`, `SettingsDialog`,
`RulesDialog`, `TagsDialog`, `ColorPickerDialog`

## 1. メインウィンドウの構成

```
┌──────────────────────────────────────────────┐
│ [更新] [ルール] [タグ] │ [設定] │ (取得中のみ進捗バー) │ ツールバー
├──────────────────────────────────────────────┤
│ [絞り込みテキスト              ]  3 件表示中 / 142 件 │
├──────────────────────────────────────────────┤
│ ┌ チャンネル一覧 ┬ 録画中 (N) ┐                 │
│ │ ビュー欄 │ 一覧                              │ タブ
│ │          │ ───── GridSplitter ─────          │
│ │          │ 詳細パネル                        │
├──────────────────────────────────────────────┤
│                                  次回更新: 42秒後 │ ステータスバー
└──────────────────────────────────────────────┘
```

タイトルは `YPBrowser`。既定サイズ 980×600（起動時に `Window` 設定で上書き）。

| 部品 | 動作 |
|---|---|
| 更新ボタン | 手動更新（最小フェッチ間隔を無視） |
| ルールボタン | ルール編集ダイアログをモーダル表示 |
| タグボタン | タグ設定ダイアログをモーダル表示 |
| 設定ボタン | 設定ダイアログをモーダル表示 |
| 進捗バー | `IsRefreshing == true` のときだけ表示（不確定アニメーション） |
| 絞り込みボックス | 1 文字入力するたびに再フィルタ。単純な部分一致で、保存しない |
| 件数表示 | `{表示中}件表示中 / {ログを除く全件}件` |
| ステータスバー左 | 通常は空。録音操作時だけ `録音開始: …` / `録音停止: …` を表示する。チャンネル数・視聴者数は出さない（件数は絞り込み欄の右にある） |
| ステータスバー右 | `次回更新: {N}秒後`、次回時刻を過ぎている間は `更新中...`（1 秒ごとに更新） |

## 2. チャンネル一覧タブ

### 2.0 ビュー欄

左端（幅 150）。「ビュー」「タグ」の 2 群に分かれ、右端に件数を出す。

| 群 | 項目 |
|---|---|
| ビュー | すべて / 新着 / お気に入り / ログ |
| タグ | `Tags` 設定の並び順そのまま（NG も含む） |

- タグの項目は、色が設定されていれば左に 8×8 の色見本を出す
- 件数はそのビューを今開いたときに実際に出る行数（[3 章](#3-ビューと絞り込み)）
- タグ設定・ルール編集を OK で閉じると作り直される

### 2.1 行の表示

星 + 4 列。各セル 2 段。

| 列 | 幅 | 1 段目 | 2 段目 |
|---|---|---|---|
| 星 | 22 | `★`（`IsFavorite`）/ `☆`。クリックでトグル | |
| チャンネル名 | 可変（最小 120） | `ChannelName` + `新` バッジ（`IsNew`） | `GenreDescription`（空なら非表示） |
| タグ | 90 | 付与されたタグのチップ（折り返し） | |
| 視聴/リレー | 75（右寄せ） | `{Listeners}/ {Relays}` | `BroadcastTimeStr` |
| ビットレート | 65（右寄せ） | `BitrateKbps`（`0` 以下は空） | `ChannelType` |

タグのチップは、タグに背景色・文字色があればそれで塗り、無ければ灰色（`#F0F0F0` / `#616161`）。

長い文字列は末尾省略（`…`）し、チャンネル名と詳細はツールチップで全文を表示する。

`GenreDescription` の書式:

```
[ジャンル - 説明] Playing: {Playing欄} 「コメント」
```

実例:

```
[PS5 - ファイナルファンタジー14 - <Free>] Playing: 110.233.212.225 via Peercast Gateway 「紅蓮のリベレーター4.1から」
```

- ジャンル・説明は空でないものだけを ` - ` で連結。両方空なら `[]` ごと省略
- Playing 欄（index.txt の 11 番目）が空なら `Playing: ` ごと省略
- コメントが空なら `「」` ごと省略
- 残った要素どうしは半角スペースで連結する。すべて空なら空文字になり、行から消える

### 2.2 色

| 対象 | 条件 | 色 |
|---|---|---|
| 行の背景 | タグあり | `TagBackColor`（色を持つ最初のタグの背景色） |
| 行の背景 | `Diff == Log` | `#EFEFEF`（タグの色より優先） |
| チャンネル名の文字色 | `Diff == New` | 緑 `#008000` |
| チャンネル名の文字色 | `Diff == Up` | 青 `#0000C8` |
| チャンネル名の文字色 | `Diff == Down` | 赤 `#C80000` |
| チャンネル名の文字色 | `Diff == Log` | 灰 `#808080` |
| チャンネル名の文字色 | `None` / `Changed` | 既定色 |

これらの色はコード・XAML 内の固定値で、`DisplaySettings` からは変更できない。

### 2.3 詳細パネル

選択行が変わると内容を差し替える（選択なしのときは全項目空）。

| 表示項目 | 値 |
|---|---|
| チャンネル名 | `ChannelName` |
| ジャンル / 説明 / コメント | `Genre` / `Description` / `Comment` |
| 視聴者 | `{Listeners}人 / リレー{Relays}` |
| ビットレート | `{BitrateKbps} {ChannelType}` |
| トラック | `TrackInfo`（`Artist / Title / Album` を空要素を除いて ` / ` 連結） |
| YP | `YpName` |
| コンタクト URL | `ContactUrl`。絶対 URI ならリンクとして扱い、クリックで既定ブラウザを開く |

高さは `GridSplitter` で 80〜300 の範囲に調整でき、終了時に保存される。

### 2.4 非表示件数バー

一覧の下端に**常時**表示する。

| 状態 | 左のテキスト | 右のボタン |
|---|---|---|
| `HiddenCount == 0` | `非表示なし` | `表示する` |
| `HiddenCount > 0` | `「一覧から隠す」タグで {N} 件を非表示中` | `表示する` |
| `ShowHidden == true` | 同上 | `隠す` |

0 件でも省略しない。省略すると、フィルタで消えた配信と YP に出ていない配信を
ユーザーが区別できなくなるため。`ShowHidden` は保存されない。

## 3. ビューと絞り込み

`ChannelFilterService.Filter(channels, view, searchText, showHidden)`。

### 3.1 ビューごとの母集合

| `Kind` | 表示名 | 条件 |
|---|---|---|
| `All` | すべて | `Diff != Log` |
| `New` | 新着 | `IsNew` |
| `Favorite` | お気に入り | `IsFavorite && Diff != Log` |
| `Tag` | タグ名 | `Diff != Log &&` そのタグを持つ |
| `Log` | ログ | `Diff == Log` |

### 3.2 隠す判定

母集合から `IsHidden` のチャンネルを除く。ただし以下の場合は除かない。

- `ShowHidden == true`（バーの「表示する」を押した状態）
- そのビュー自身が `Hidden` のタグのビュー（NG の中身は NG のビューから確認できる）

### 3.3 絞り込みテキスト

前後空白を除去し、空でなければ以下のいずれかに部分一致（大文字小文字無視）するものだけを残す。
正規表現としては解釈しない。

```
ChannelName / Genre / Description / Comment
```

### 3.4 表示順

「`IsHighlighted` を先頭」→「`Listeners` 降順」。

### 3.5 非表示件数

`CountHidden(channels, view, searchText)` = 絞り込み後の母集合のうち `IsHidden` の件数。
絞り込みで消えた分は数えない（別の理由で消えているため）。
`Hidden` のタグ自身のビューでは常に 0。

## 4. コンテキストメニュー（チャンネル一覧の右クリック）

すべて**選択中の行**に対して動作する。

| 項目 | 動作 |
|---|---|
| 再生 | 既定プレイヤーで開く（下記 4.1） |
| コンタクトURLを開く | `ContactUrl` を既定ハンドラで開く（空なら何もしない） |
| 統計URLを開く | `StatsUrl` を既定ハンドラで開く（空なら何もしない） |
| お気に入り（切替） | 星と同じトグル（下記 4.2） |
| この条件でルールを作成... | 下記 4.4 |
| コピー（チャンネル情報） | 下記 4.3 の書式でクリップボードへ |
| コピー（プレイリストURL） | `StreamUrl` をクリップボードへ |
| 録音/録画 | 録音の開始・停止をトグル |

いずれも失敗時に UI 上のエラー表示はない（URL を開く操作は例外を握りつぶす）。

### 4.1 再生時のプレイヤー選択

```
IsDefault == true のプレイヤー
  └─ 無ければ Players の先頭
        └─ 1 つも無ければ OS の既定ハンドラで StreamUrl を開く
```

プレイヤー起動時は `ArgumentTemplate` の `{url}` を `StreamUrl` に置換し、`UseShellExecute = false` で起動する。
プレイリストファイルは生成しない。

### 4.2 星のトグルで作られるルール

チャンネル名の完全一致でお気に入りタグを付ける自動生成ルール。
詳細は [matching.md](matching.md#7-星ボタン自動生成ルール)。
操作後すぐに保存し、全チャンネルを再判定して表示を更新する。

### 4.3 「コピー（チャンネル情報）」の書式

```
{チャンネル名} ({視聴者数}/ {リレー数})
 [{ジャンル} - {説明}]「{コメント}」
 {アーティスト / アルバム / 曲名}
{コンタクトURL}
```

コメントが空なら `「」` ごと、トラック情報が全て空ならその行ごと出力しない。

### 4.4 「この条件でルールを作成」の初期値

選択行の値を入れた新しいルールを作り、それを選択した状態でルール編集ダイアログを開く。

| 項目 | 値 |
|---|---|
| `Name` | `Genre` と `Description` を空要素を除き半角スペースで連結（空ならチャンネル名） |
| 条件 | 1 件（`Description` / `Contains` / 上と同じ文字列） |
| `Order` | 既存ルールの最大 + 1 |

キャンセルで閉じれば保存されない。

## 5. 録画中タブ

タブ見出しは `録画中 (N)`。N は**終了済みを含む**エントリ数。

| 列 | 幅 | 内容 |
|---|---|---|
| 停止 | 44 | `IsActive` のときだけ表示されるボタン |
| チャンネル名 | 140 | `DisplayName`（終了後は `…（終了）`）。ツールチップは保存先フルパス |
| チャンネル詳細 | 可変 | 録音開始時点の `GenreDescription` |
| ダウンロードステータス | 130（右寄せ） | `(H:MM:SS) 1,234KB` |
| リトライ | 40（右寄せ） | 再試行回数。`0` のときは空欄 |

| 挙動 | 仕様 |
|---|---|
| 追加位置 | 新しい録音を先頭に挿入 |
| 行の背景 | 録音中は `#EDE7F6`、終了後は白 |
| 終了時 | エントリは削除されず `IsActive = false` になって残る |
| 経過時間 | 録音中のみ 1 秒ごとに進む。終了後は停止時点で固定 |
| 永続化 | しない（アプリ終了で消える） |

## 7. 起動と終了

```
起動: App.OnStartup
        ├─ 設定読み込み（旧形式ならタグ方式 / 新しい動作設定へ移行して保存）
        ├─ MainWindow を作る
        ├─ InitializeApp
        │    ├─ 通知サービス初期化
        │    ├─ トレイアイコンの受け口を用意（この時点ではまだ出さない）
        │    ├─ ビュー欄の構築
        │    ├─ 1 秒周期タイマー開始（次回更新カウントダウン + 録音の経過時間）
        │    ├─ 自動更新開始（即座に 1 回取得）
        │    └─ Window.Width/Height、SplitterPosition を復元
        └─ Behavior.StartupState に従って出す
             ├─ Normal    … 通常表示
             ├─ Minimized … 最小化して表示（タスクバーに残す）
             └─ Tray      … ウィンドウを出さず、トレイアイコンだけ

終了: Closing
        └─ Width / Height / SplitterPosition を保存
```

設定の読み込みを `App.OnStartup` で行うのは、`Behavior.StartupState` を見てからでないと
ウィンドウの出し方を決められないため（以前は `MainWindow.Loaded` で読んでいた）。
「トレイに格納した状態で起動」ではウィンドウを一度も出さないので、初期化を `Loaded` に
置いたままだとアプリが動き出さない。

起動時のビューは常に「すべて」、`ShowHidden` は常にオフ（どちらも保存されない）。

### トレイ常駐

| 契機 | 動作 |
|---|---|
| 最小化（`MinimizeButtonAction = MinimizeToTray`） | ウィンドウを隠してタスクバーからも消し、トレイアイコンを出す |
| 最小化（`KeepInTaskbar`） | 通常の最小化。アイコンは出ない |
| 起動時（`StartupState = Tray`） | ウィンドウを出さずアイコンだけ出す |
| アイコンを左クリック / ダブルクリック | ウィンドウを復帰させ、アイコンを消す |
| アイコンを右クリック | メニュー（`YPBrowser を表示` / `終了`） |
| 閉じるボタン（✕） | 常に終了 |

アイコンは**トレイに格納している間だけ**出す。ウィンドウが見えているのにアイコンも出ていると、
同じアプリの入口が 2 つあるように見えるため。したがってトレイを使わない設定のままなら
アイコンは一度も出ない。

ツールチップは `YPBrowser` + `N 配信 / M 視聴者`。更新のたびに書き換える。

エクスプローラーが再起動するとアイコンは消えるので、`TaskbarCreated` を受けて登録し直す。

起動時に「最小化」を選んだ場合は、`MinimizeButtonAction` に関係なくタスクバーへ置く。
「起動時の状態」で最小化を選んだ人が、狙っていないトレイ格納に化けるのを防ぐため。

## 8. ダイアログ

### 設定ダイアログ（モーダル / 740×600）

左のナビゲーションで 6 ページを切り替える。各項目にアイコンが付き、選択は角丸の塗り（半径 6px、行の高さ 34px）。

```
全般 / Yellow Pages / 表示 / 通知 / ダウンロード / ネットワーク
```

- 「全般」が先頭。旧「プレイヤー」ページと旧「動作」ページはここへ統合された
- 「ネットワーク」はほとんど触らない技術設定なので最下段

下部に **OK・キャンセル**。編集しているのは設定の複製で、本体へ書き戻すのは OK のときだけ。
キャンセルはどのページの変更も残さない（[settings.md](settings.md#4-設定の反映と保存のタイミング)）。

#### カード行

コンテンツは「1 設定 = 1 カード行」で組む。カードは共通のユーザーコントロール
`Views/Controls/SettingCard.cs` 1 つで、全ページがこれを使う。

```
┌────────────────────────────────────────────┐
│ 🖵  項目名  [バッジ]                [コントロール] │
│    説明文（任意）                              │
└────────────────────────────────────────────┘
```

| 種別 (`Variant`) | 見た目 |
|---|---|
| `Card` | 単独の設定行。背景 `#FBFBFB` / 枠 1px / 半径 6px / 下マージン 6px |
| `GroupHeader` | 子行を束ねる枠の見出し。枠は外側の `Border` が描く |
| `SubRow` | 見出しの下に積む子行。左を 42px 字下げし、上に区切り線 |

関連する設定はグループ見出し（小さい灰色テキスト）でまとめる。
単独の設定のチェックボックスはトグルスイッチ（`ToggleSwitchStyle`）にする。
一覧の行に付く有効/無効のチェックボックスはそのまま（複数項目の選択であって、
1 つの設定の入り切りではないため）。

#### 「全般」ページ

| 設定 | 選択肢 |
|---|---|
| 起動時の状態 | 通常表示 / 最小化 / トレイに格納 |
| 最小化ボタンを押したとき | タスクバーに残す / トレイに格納 |
| チャンネル一覧の自動更新 | 60 秒ごと / 30 秒ごと / 120 秒ごと / 更新しない |
| 再生 > 外部プレイヤー | 一覧 + 行ごとの「⋯」メニュー（編集 / 既定にする / 削除） |

- 閉じるボタン（✕）は常に終了。設定項目は設けない
- 自動更新はプリセットのみ。秒数の自由入力は廃止
- 既定のプレイヤーは行に「既定」バッジで示す（チェックボックスは持たない）
- プレイヤーの編集は小さいモーダル（[外部プレイヤー編集ダイアログ](#外部プレイヤー編集ダイアログモーダル--460幅)）で行う

### 外部プレイヤー編集ダイアログ（モーダル / 460幅）

名前・実行ファイル（参照ボタン付き）・引数の 3 つだけ。`{url}` に配信 URL が入る旨の説明はここに置く。
OK で複製上のプレイヤーへ書き戻す（設定本体に届くのは、設定ダイアログの OK を押したとき）。

### ルール編集ダイアログ（モーダル・独立ウィンドウ / 820×560）

編集は設定の**複製**に対して行い、OK のときだけ書き戻す。キャンセルは何も変えない。

```
┌ 追加 複製 削除 ↑ ↓ ┬──────────────────────┐
│ ☑ ルール名  [チップ] │ ルール名 [            ]  │
│ ☑ ルール名  [チップ] │ 条件  [すべて満たす ▼]   │
│   （無効はグレー）   │  [チャンネル名▼][一致▼][正規表現▼][パターン] [−] │
│                     │  [条件を追加] 現在の一覧で N 件にマッチ [該当を確認] │
│                     │ 付与するタグ [チップ ×] [▼] [追加]  │
│                     │ ☐ ここで評価を打ち切る            │
│ 上から順に評価       │                                  │
└─────────────────────┴──────────────────────┘
```

| 部品 | 動作 |
|---|---|
| 一覧の並び | そのまま評価順（`Order` は OK 時に 0 から振り直す） |
| `★ 自動生成` の表示 | `IsAuto == true` のルールに出す |
| マッチ件数 | 条件を変えるたびに、現在読み込んでいる一覧に対して再評価 |
| 該当を確認 | 実際に一致した行（チャンネル名 + 詳細）を最大高 150 で出す |
| インラインエラー | 不正な正規表現を赤字で表示。この間はマッチ件数 0 |
| タグの追加 | 既存タグを選ぶか、未知の名前を入力して新規作成 |
| OK | 不正な正規表現が 1 件でも残っていれば警告を出して**閉じない** |

OK で閉じると、その場で全チャンネルを再判定してビュー欄と一覧を作り直す。

### タグ設定ダイアログ（モーダル・独立ウィンドウ / 760×460）

| 列 | 内容 |
|---|---|
| タグ | 名前（組み込みタグも改名できる。参照は ID なので壊れない） |
| 見た目 | 実際の行と同じ塗りのプレビュー + `文字` `背景` `×`（色を外す） |
| 既定の扱い | 通常表示 / 強調して上へ / 一覧から隠す |
| 通知 | チェックボックス |
| 通知音 | パス + `...`（wav の選択）。空欄なら既定音 |
| 使用 | そのタグを付けているルールの数。0 なら削除候補 |

- 並べ替え（↑↓）はそのまま**行の色の優先順**になる
- 組み込みタグ（お気に入り / NG）は削除ボタンが無効になる
- OK 時、消したタグを参照していたルールからはその ID を取り除く
- 編集は複製に対して行い、OK のときだけ書き戻す

### 色の選択ダイアログ（モーダル / 320×可変）

パレット（36 色）・RGB スライダー・16 進テキストのどれでも指定でき、結果をその場でプレビューする。

## 9. コントロールの見た目

WPF 既定（Aero2）のグラデーションは使わない。共通スタイルは `App.xaml` でマージする
3 つの辞書に置く。

| ファイル | 中身 |
|---|---|
| `Themes/Palette.xaml` | 色だけ。他の 2 つが**それぞれマージ**する（兄弟辞書の `StaticResource` 参照はマージ順に依存して壊れるため） |
| `Themes/Buttons.xaml` | ボタン |
| `Themes/Controls.xaml` | テキストボックス / コンボボックス / チェックボックス / 一覧 / タブ / スクロールバー |

アクセント色は `#0067C0`（一覧の `新` バッジと同じ）。

### 9.1 ボタン

| スタイル | 見た目 | 使う場所 |
|---|---|---|
| 既定（暗黙適用） | 白地・1px 枠・角丸 5 | ほぼ全部 |
| `AccentButtonStyle` | 青地・白文字 | 更新ボタン |
| `SubtleButtonStyle` | 枠なし・透明 | 星、タグの `×`、一覧内の小さいボタン |
| `DangerButtonStyle` | 白地・赤文字と赤枠 | 録画の停止 |

- `IsDefault="True"` のボタン（各ダイアログの OK）は自動でアクセント色になる
- ホバー / 押下は半透明の板を重ねて表現する（`Background` は差し替えない）。
  色見本ボタンのように `Background` を自前で持つボタンでも色が消えないため
- 押下時は 0.97 倍に縮む（50ms）
- キーボードフォーカス時だけアクセント色のリングを出す（マウス操作では出さない）
- `Button` に個別の `Style` をインラインで書くときは `BasedOn` を必ず付ける（付けないと共通スタイルが外れる）

### 9.2 ボタン以外

| コントロール | 見た目 |
|---|---|
| テキストボックス | 白地・1px 枠・角丸 4。フォーカス時はアクセント色の下線（枠の太さは変えないので文字がずれない） |
| コンボボックス | テキストボックスと同じ枠 + 右に山形。ドロップダウンは角丸 6・影付きの浮いたパネル |
| チェックボックス | 16×16 の角丸。オンでアクセント色に塗り、白のチェックを出す |
| 一覧の行 | 選択はアクセント色の**半透明**の板 + 左端 3px の帯。ホバーは薄い黒の板 |
| タブ | 枠で囲まない。選択中はアクセント色の下線と太字 |
| スライダー | 4px の細いレール。つまみより左をアクセント色で塗り、つまみは丸。**横向き専用**（縦向きで使うならテンプレートを足す） |
| スクロールバー | 幅は既定（17）のまま、つまみだけ細い角丸。矢印ボタンは出さない |
| 一覧のヘッダー / ステータスバー | `#F7F8FA`（システム色 `ControlBrush` は使わない。OS のテーマで灰色になるため） |

- 行の選択を半透明にしているのは、タグの色で塗られた行でも下の色が残るようにするため
- スクロールバーの幅を変えないのは、一覧のヘッダーが 17px の余白を前提に罫線を合わせているため
- `TextBox` / `ComboBox` / `ListBoxItem` などに個別の `Style` をインラインで書くときは、
  ボタンと同じく `BasedOn` を必ず付ける
- コンボボックスのテンプレートを自前で書くときは、選択部分の `ContentPresenter` に
  `ContentTemplateSelector="{TemplateBinding ItemTemplateSelector}"` まで渡す。
  これが無いと `DisplayMemberPath` が効かず、選択中の項目が `ToString()` の生の値で出る
- 色の選択のスライダーは `IsMoveToPointEnabled`（クリックした位置へ直接飛ぶ）。
  色選びでは 1 目盛りずつの微調整よりも、狙った位置へ一度で動くほうが速いため
